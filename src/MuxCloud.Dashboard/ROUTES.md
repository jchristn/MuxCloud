# Mux Cloud dashboard: route inventory

This table drives the dashboard build (DASHBOARD_STYLE_AND_USABILITY.md "Route Inventory"). The product's core job
comes first: pick a machine and use it as if you were sitting at it. Account pages follow, then system
administration and observability for operators.

Every route is served by the Mux Cloud server from `src/MuxCloud.Dashboard/dist` with SPA fallback, on the same origin
as the API (`/v1.0/...`), the relay (`/m/{machineId}/...`), and the WebSocket surfaces.

| Route                                                       | User job                                            | Primary role(s) | Backend resources                                                                                                                | Table/filter needs                                                               | Actions and modals                                                                                                              | Empty/error states                                                                                          |

| `/signup`                                                   | Create an account                                   | Anyone          | `POST /auth/signup`                                                                                                              | None                                                                             | Terms and Privacy acceptance, password reveal                                                                                   | Email in use, invalid fields, lockout                                                                       |

| `/forgot`                                                   | Request a reset link                                | Anyone          | `POST /auth/password/forgot`                                                                                                     | None                                                                             | None                                                                                                                            | Lockout, network failure.
